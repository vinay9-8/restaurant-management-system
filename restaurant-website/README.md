# Spice Garden

A polished, responsive sample restaurant website built with semantic HTML5, custom CSS, Bootstrap 5.3, Bootstrap Icons, and vanilla JavaScript.

## Project files

- `index.html` — page structure and content
- `style.css` — theme, responsive layout, and interaction styling
- `script.js` — menu filters, active navigation, demo forms, and other interactions

## Run locally

### VS Code and Live Server

1. Open the `restaurant-website` folder in Visual Studio Code (`File` → `Open Folder…`).
2. Install the **Live Server** extension by Ritwick Dey if it is not already installed.
3. Open `index.html`, then select **Go Live** in the VS Code status bar (or right-click the file and choose **Open with Live Server**).
4. Live Server opens the website in your browser and refreshes it when you save changes.

You can also open `index.html` directly in a browser. An internet connection is needed for the Bootstrap CDN, Google Fonts, Bootstrap Icons, and Unsplash images.

## Demo behavior and content

- Menu category buttons filter the sample dishes. **Order Now** displays an informational demo message; it does not place an order or process payment.
- Reservation and contact forms validate in the browser and display a confirmation-style demo message. They do **not** send or store information. Real reservations and messages require a backend integration.
- Today's Special, discount text, contact details, prices, and customer reviews are sample content only. No actual promotion or verified customer testimonials are implied.
- The map is a visual placeholder; no location service is connected.

## Accessibility and responsive design

The site includes semantic landmarks, a skip link, labeled form fields, descriptive image alt text, keyboard focus indicators, responsive Bootstrap layouts, mobile navigation, and reduced-motion support.
